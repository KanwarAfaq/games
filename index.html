What is Kanwar Arcade?

Kanwar Arcade is a free set of browser games made by Kanwar Afaq. It has 5 games: Starfall (space shooter), Brick Rally (brick breaker), Serpentine (snake game), Skyhop (one-tap flyer), Lumenfall (3d adventure). Every game runs in a web page with no download, account or ads.

Frequently asked questions

What is Kanwar Arcade?

Kanwar Arcade is a free collection of five browser games: Starfall, Brick Rally, Serpentine, Skyhop and Lumenfall. They run on any modern device with no download, no account and no ads.

Are the games really free?

Yes. Every game is free, there are no in-app purchases and nothing to install.

Do the games work on a phone?

Starfall, Brick Rally, Serpentine and Skyhop work with touch as well as keyboard and mouse. Lumenfall is a 3D game that needs a keyboard and mouse, so it is best on a desktop or laptop.

Where are my high scores saved?

Best scores are saved in your own browser with local storage. They never leave your device and there is no account to make.

Which game should I try first?

Try Starfall for fast action, Skyhop for a one-tap challenge, Serpentine for a classic with a twist, and Lumenfall for a 3D adventure.
