What is Kanwar Arcade?

Kanwar Arcade is a free set of browser games made by Kanwar Afaq. It has 13 games: Starfall (space shooter), Brick Rally (brick breaker), Serpentine (snake game), Skyhop (one-tap flyer), Lightmerge (puzzle game), Driftrock (asteroid shooter), Lumenfall (3d adventure), Neon Velocity (3d racing game), Starfall Protocol (3d shooter), Aether Run (neon hover racer), Moonlit Grove (fantasy survival), Park Dash (kids running race), Serpent Studio (customizable snake). Every game runs in a web page with no download, account or ads.

Frequently asked questions

What is Kanwar Arcade?

Kanwar Arcade is a free collection of 13 browser games: Starfall, Brick Rally, Serpentine, Skyhop, Lightmerge, Driftrock, Lumenfall, Neon Velocity, Starfall Protocol, Aether Run, Moonlit Grove, Park Dash, Serpent Studio. They run in any modern browser with no download, no account and no ads.

Are the games really free?

Yes. Every game is free, there are no in-app purchases and nothing to install.

Do the games work on a phone?

Starfall, Brick Rally, Serpentine, Skyhop, Lightmerge, Driftrock, Aether Run, Moonlit Grove, Park Dash, Serpent Studio work with touch as well as keyboard and mouse. Lumenfall and Neon Velocity and Starfall Protocol are 3D games that need a keyboard, so they are best on a desktop or laptop.

Where are my high scores saved?

Best scores are saved in your own browser with local storage. They never leave your device and there is no account to make.

Which game should I try first?

Try Starfall for fast action, Skyhop for a one-tap challenge, Lightmerge for a puzzle, Park Dash for kids running, Serpent Studio for customizable snake, Aether Run for neon hover racing, Moonlit Grove for fantasy survival, Lumenfall for a 3D adventure, Neon Velocity for racing and Starfall Protocol for a 3D shooter.
